Punjab Education Intelligence Platform

Prototype for the Punjab AI-Powered Education & Learning System. Curriculum → knowledge → learning → assessment → diagnosis → personalised improvement.

Open the GitHub repository How to run the live prototype
GitHub Pages hosts this public briefing only. The working portal is a Python (FastAPI) application with a SQLite knowledge base, so it cannot run on GitHub Pages. Clone the repository and run run.bat, or deploy the included Dockerfile / Render blueprint, then open the app in a browser.

Prototype scope

Grade 7 General Science · PCTB-aligned · 5 chapters · hero chapter: Photosynthesis and Nutrition in Plants.

Run on any computer

  1. Install Python 3.11+
  2. Download or clone the GitHub repository
  3. Double-click run.bat (Windows) or run python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
  4. Open http://127.0.0.1:8000
